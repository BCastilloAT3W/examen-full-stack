# Exercise 2

## Description

This page is used to register sensors. To create a new sensor, we go to the _Inicio_ page and fill the form with the sensor's information. The registered sensors appear on the sidebar,
if we click on one of them we go to the sensor's page and there we can see all its information.

![screenshot](./.github/images/screenshot.png)

**But there's a problem:** when we submit the form to create a new sensor the new sensor does not appear on the sidebar until we refresh the page. Can you fix this?

## Notes

This project storage system is file based, so you don't need to worry about setting up a database.
